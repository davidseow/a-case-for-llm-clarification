# Ask If Unclear

An eleven-slide, ten-minute talk making the case for ending important prompts with
three small words: `ask if unclear`.

The argument runs through what a language model is actually doing. It predicts the
next chunk of text and commits to the most probable one, so an ambiguous prompt is
never recognised as ambiguous — it is quietly resolved into a single confident
answer, and the near-tie that decided it never reaches you. Asking the model to
check doesn't install a gauge for confusion; it lifts a brake, because following an
explicit instruction is the thing the model has been trained hardest to do.

Written for a mixed, mostly non-technical audience. Every figure in the deck is
invented, and the slides say so where it matters.
